# FitLog

FitLog is a modern workout library and daily workout planning website. Users can browse workouts, view workout details, add exercises to today's plan, and save workouts for later.

## Technologies Used

- Next.js
- React
- JavaScript
- Tailwind CSS
- DaisyUI
- React Icons
- REST API
- LocalStorage

## Features

- Browse workouts from the FitLog API
- View detailed information about each workout
- Add workouts to Today's Plan
- Save workouts for later
- Mark planned workouts as done
- Remove workouts from the plan or saved list
- Sort workouts by duration, calories, or rating
- Plan and Saved counters in the navbar
- Responsive design for mobile, tablet, and desktop
- LocalStorage support for saving workout plans

## API

### All Workouts

https://api.abcz.workers.dev/api/fitlog

### Single Workout

https://api.abcz.workers.dev/api/fitlog/:id
